# Python DevOps Project

## Project Description

This project is a simple Python Flask web application built as part of my AWS DevOps learning journey.

## Technologies Used

- Python
- Flask
- AWS EC2
- Linux
- Git

## Endpoints

| Endpoint | Description |
|----------|-------------|
| / | Home Page |
| /health | Health Check |
| /version | Application Version |

## Run the Project

Activate virtual environment:

```bash
source venv/bin/activate
```

Run the application:

```bash
python app.py
```

Open in browser:

```
http://<EC2-PUBLIC-IP>:5000
```
